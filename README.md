# Bank Account

A Java console app that models a small bank: normal and chequing
accounts, deposits, withdrawals with overdraft rules, and a menu.

## What I practised
- Classes, objects and constructors
- Encapsulation (private fields with rules)
- Inheritance (ChequingAccount extends BankAccount)
- Polymorphism and interfaces

## How to run
Open in IntelliJ and run Main.java
